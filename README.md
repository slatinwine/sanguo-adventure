# 三国乱世行 · 文字冒险

「三国乱世行」AI 文字冒险游戏的镜像入口页：汉室倾颓、群雄并起，由 AI 主理人依史实推演剧情，赤壁、官渡、虎牢关等名场面等你亲历。本仓库为一个单文件静态引导页，实际的 AI 剧情推演运行在官方源站。

## ✨ 功能特性

- 仿古宣纸风视觉：宋体排印、朱砂分隔线、背景水墨底图，贴合三国时代气质
- 自动跳转：通过 `meta refresh` 与 JavaScript 兜底双保险，3 秒后跳转至官方源站
- 手动入口：提供「立即入局」按钮，自动跳转失效时可点击前往
- 移动端适配：响应式布局，手机浏览器可直接打开
- 零依赖：单文件纯静态页面，无任何外部构建或安装步骤

## 🚀 使用方法

1. 用浏览器直接打开 `index.html` 即可
2. 页面将在 3 秒后自动跳转至游戏官方源站（`sanguo-adventure-15794.app.workbuddy.host`）；若未自动跳转，点击页面上的「立即入局」按钮

## 🛠️ 技术栈

- HTML / CSS / 原生 JavaScript（单文件，无依赖）
- 部署方式：任意静态托管（如 GitHub Pages）
